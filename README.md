# 🔗 URL Shortener

A simple **URL Shortener** built with Python using the `pyshorteners` library.

This program takes a long URL from the user and generates a shorter link using **TinyURL**.

## 🚀 Features

* Takes a URL as user input
* Shortens the URL using TinyURL
* Displays the shortened link
* Simple command-line interface

## 🛠️ Technologies Used

* Python
* PyShorteners
* TinyURL

## 📦 Installation

First, install the required library:

```bash
pip install pyshorteners
```

## ▶️ How to Run

Run the Python file:

```bash
python url_shortener.py
```

Then enter the URL you want to shorten.

### Example

```text
Enter the URL: https://www.example.com/some-long-url
The shortened link: https://tinyurl.com/xxxxx
```
